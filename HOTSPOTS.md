# Hornet Pure-DS Optimization Tracker

Living tracker of data-structure optimizations (`DS-1`–`DS-7`) for Hornet GPU dynamic graphs: what was proposed, what was actually implemented and fixed, current status, and measured impact vs. baseline. All optimizations target `src/improved/` only (`src/algorithms/` remains untouched).

| ID | Difficulty | Target Files (`src/improved/`) | Proposed Fix | What We Actually Did & Fixes | Status | Measured Impact vs Baseline |
| :--- | :--- | :--- | :--- | :--- | :---: | :--- |
| **DS-1** | Easy | `block_array.cuh`, `memory_manager.cuh` | Replace `cudaMalloc`/`cudaFree` with stream-ordered `cudaMallocAsync`/`cudaFreeAsync` (`cudaMemPool_t`) and replace zero-filled `std::vector` staging with uninitialized `cudaMallocHost` pinned staging | Kept `cudaMallocAsync`/`cudaFreeAsync` (`256 MiB` release threshold + OOM trim); **replaced `cudaMallocHost`/`cudaFreeHost`** (which caused `580.1 + 193.5 ms` host pin/unpin stalls and GPU downclocking) with **uninitialized prefix-sized pageable staging (`new vid_t[take * block_size_]`)** + synchronous `cudaMemcpy` | **Done** | `in-2004 1M` `nsys`: `cudaFree` `148.3 -> 7.2 ms`, `cudaMemcpy` `92.8 -> 31.3 ms`; with `DS-4`, init is **`2.92x–19.29x` faster** (`7.39 ms` `dblp`, `28.54 ms` `in-2004`, `92.41 ms` `soc-LJ`, `108.83 ms` `cage15`, `155.75 ms` `kron`) |
| **DS-2** | Easy | `batch_workspace.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Tight `2 * vid_bits` key packing + partial `end_bit` radix sort, 1-pass `Flagged` + gather, GPU `ExclusiveSum` `d_move_offsets`, and persistent pinned workspace metadata | Implemented as proposed (`end_bit = 2 * vid_bits`, 1-pass `counting_iterator` `Flagged` + gather, GPU `d_move_offsets`, `cudaHostAlloc` workspace metadata); **fixed shared-memory `s_write_base` WAR race** in `delete_compact_block_kernel` using per-thread register `cur_base` (also patched in `src/baseline/batch_delete.cuh`) | **Done** | `in-2004 1M` `nsys`: `DeviceRadixSort` `622.8 -> 542.7 us` (`16 -> 12` passes), `adj_move` `387.1 -> 319.7 us`; `1M` insert/delete up to **`1.21x`** (`cage15` insert) and **`1.36x`** (`soc-LJ` delete); `bench_tc` **`1.34x`** (`soc-LJ 100K`) |
| **DS-3** | Easy | `batch_workspace.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Single-block `<<<1, 256>>>` shared-memory preprocessing (`BlockRadixSort`) fast path for `batch_size <= 1024` | Implemented `preprocess_small_batch_kernel<<<1, 256>>>`; **tuned threshold from `1024` down to `256`** because the single-thread dedup/RLE/scan loop at `B = 1000` was slower (`0.60x–0.88x`) than multi-block CUB | **Done** | `B = 1..100` (`in-2004`, `soc-LJ`, `cage15`): **`1.19x–1.66x`** (`insert`) and **`1.29x–1.74x`** (`delete`); `B = 1000` regression removed (`in-2004` delete `1.46x`) |
| **DS-4** | Easy | `CMakeLists.txt`, `bit_tree.cuh`, `block_array.cuh`, `memory_manager.cuh`, `hornet_graph.cuh` | Parallelize CSR initialization with OpenMP (`-fopenmp`) using a 2-pass degree histogram, per-bin `BlockArray` preallocation (`mark_prefix_used`), and concurrent staging | Implemented 2-pass OpenMP histogram + `preallocate_bin_for_init` + `schedule(dynamic, 4096)` staging; **fixed missing `#pragma omp barrier`** before `#pragma omp single` that caused `bench_memory` race/crash | **Done** | Combined with `DS-1`: `bench_init` dropped from `142.6–503.7 ms` down to **`7.39–155.75 ms`** across all 5 graphs (**`2.92x–19.29x` faster**) |
| **DS-5** | Medium | `batch_insert.cuh`, `batch_delete.cuh` | Maintain sorted adjacency lists via GPU parallel merge on insert; replace full-degree scans with `O(batch_deg * log deg)` lookup in `check_cross_dups` & `delete_mark`; multi-block hub compaction (`deg > 256`) | — | **Pending** | Target: `check_cross_dups` (`46.7%` GPU kernel share on `in-2004 1M`), `kron` `delete` (`22.08 ms` `1M`), and Dynamic TC post-insert precision |
| **DS-6** | Medium | `hornet_graph.cuh`, `memory_manager.cuh`, `block_array.cuh` | Full GPU-side CSR $\to$ Hornet initialization (`row_offsets`/`col_indices` upload + GPU bin prefix offsets + GPU edge scatter) | — | **Pending** | Target: eliminate remaining `7.39–155.75 ms` host init loop and staging copy |
| **DS-7** | Hard | `bit_tree.cuh`, `memory_manager.cuh`, `block_array.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Move `BitTree` bitmasks and block allocation/reclamation to GPU via warp-aggregated atomics (`__ffsll`, `atomicAnd`/`atomicOr`, overflow slab handling) | — | **Pending** | Target: **`70.5%–87.4%` host serial share** on `1M` insert (**`3.39x–7.96x`** Amdahl ceiling) |
