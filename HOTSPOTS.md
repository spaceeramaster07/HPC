# Hornet Pure-DS Optimization Tracker

Living tracker of data-structure optimizations (`DS-1`–`DS-7`) for Hornet GPU dynamic graphs: what was proposed, what was actually implemented and fixed, current status, and measured impact vs. baseline. All optimizations target `src/improved/` only (`src/algorithms/` remains untouched).

| ID | Difficulty | Target Files (`src/improved/`) | Proposed Fix | What We Actually Did & Fixes | Status | Measured Impact vs Baseline |
| :--- | :--- | :--- | :--- | :--- | :---: | :--- |
| **DS-1** | Easy | `block_array.cuh`, `memory_manager.cuh` | Replace `cudaMalloc`/`cudaFree` with stream-ordered `cudaMallocAsync`/`cudaFreeAsync` (`cudaMemPool_t`) and replace zero-filled `std::vector` staging with uninitialized `cudaMallocHost` pinned staging | Kept `cudaMallocAsync`/`cudaFreeAsync` (`256 MiB` release threshold + OOM trim); **replaced `cudaMallocHost`/`cudaFreeHost`** (which caused `580.1 + 193.5 ms` host pin/unpin stalls and GPU downclocking) with **uninitialized prefix-sized pageable staging (`new vid_t[take * block_size_]`)** + synchronous `cudaMemcpy` | **Done** | `in-2004 1M` `nsys`: `cudaFree` `148.3 -> 7.2 ms`, `cudaMemcpy` `92.8 -> 31.3 ms`; with `DS-4`, init is **`2.92x–19.29x` faster** (`7.39 ms` `dblp`, `28.54 ms` `in-2004`, `92.41 ms` `soc-LJ`, `108.83 ms` `cage15`, `155.75 ms` `kron`) |
| **DS-2** | Easy | `batch_workspace.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Tight `2 * vid_bits` key packing + partial `end_bit` radix sort, 1-pass `Flagged` + gather, GPU `ExclusiveSum` `d_move_offsets`, and persistent pinned workspace metadata | Implemented as proposed (`end_bit = 2 * vid_bits`, 1-pass `counting_iterator` `Flagged` + gather, GPU `d_move_offsets`, `cudaHostAlloc` workspace metadata); **fixed shared-memory `s_write_base` WAR race** in `delete_compact_block_kernel` using per-thread register `cur_base` (also patched in `src/baseline/batch_delete.cuh`) | **Done** | `in-2004 1M` `nsys`: `DeviceRadixSort` `622.8 -> 542.7 us` (`16 -> 12` passes), `adj_move` `387.1 -> 319.7 us`; `1M` insert/delete up to **`1.21x`** (`cage15` insert) and **`1.36x`** (`soc-LJ` delete); `bench_tc` **`1.34x`** (`soc-LJ 100K`) |
| **DS-3** | Easy | `batch_workspace.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Single-block `<<<1, 256>>>` shared-memory preprocessing (`BlockRadixSort`) fast path for `batch_size <= 1024` | Implemented `preprocess_small_batch_kernel<<<1, 256>>>`; **tuned threshold from `1024` down to `256`** because the single-thread dedup/RLE/scan loop at `B = 1000` was slower (`0.60x–0.88x`) than multi-block CUB | **Done** | `B = 1..100` (`in-2004`, `soc-LJ`, `cage15`): **`1.19x–1.66x`** (`insert`) and **`1.29x–1.74x`** (`delete`); `B = 1000` regression removed (`in-2004` delete `1.46x`) |
| **DS-4** | Easy | `CMakeLists.txt`, `bit_tree.cuh`, `block_array.cuh`, `memory_manager.cuh`, `hornet_graph.cuh` | Parallelize CSR initialization with OpenMP (`-fopenmp`) using a 2-pass degree histogram, per-bin `BlockArray` preallocation (`mark_prefix_used`), and concurrent staging | Implemented 2-pass OpenMP histogram + `preallocate_bin_for_init` + `schedule(dynamic, 4096)` staging; **fixed missing `#pragma omp barrier`** before `#pragma omp single` that caused `bench_memory` race/crash | **Done** | Combined with `DS-1`: `bench_init` dropped from `142.6–503.7 ms` down to **`7.39–155.75 ms`** across all 5 graphs (**`2.92x–19.29x` faster**) |
| **DS-5** | Medium | `batch_workspace.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Maintain sorted adjacency lists via GPU parallel merge on insert; replace full-degree scans with `O(batch_deg * log deg)` lookup in `check_cross_dups` & `delete_mark`; multi-block hub compaction (`deg > 256`) | Maintained sorted adjacency lists on insert (`dedup=1/0`) via 3-tier GPU Merge Path (`<= 256` warp, `257–4096` single-block prefix-skip smem, `> 4096` / realloc `1024`-tile merge with `64M`-edge bounded chunked `d_merge_scratch` + dead Phase-1 buffer reuse in `batch_workspace.cuh`) and preserved order on delete; switched `check_cross_dups_sorted_kernel` & `delete_mark_sorted_kernel` to `O(batch_deg * log old_deg)` `dev_lower_bound`; added race-free multi-block hub compaction (`count -> ExclusiveSum -> d_merge_scratch -> scatter`) for `> 16384` (and `4097–16384` when `num_large <= 512`) while keeping 1-pass prefix-skipping `delete_compact_block_kernel` for `257–4096` (**tuned thresholds after profiling** showed `> 1024` scratch copies doubled `kron 1M` DRAM traffic) | **Done** | `in-2004 1M` `nsys`: `check_cross_dups` `1.99 ms (44.7%) -> 0.54 ms (10.5%)` (**`3.70x`** vs baseline, **`3.91x`** vs pre-DS-5); `kron` `delete`: `3.94 -> 2.18 ms` (`10K`, **`1.80x`**), `11.19 -> 5.65 ms` (`100K`, **`1.98x`**), `21.03 -> 10.38 ms` (`1M`, **`2.03x`**), `38.47 -> 25.38 ms` (`10M`, **`1.52x`**); `1M` `delete`: `soc-LJ` `10.99 -> 5.33 ms` (**`2.06x`**), `cage15` `7.17 -> 4.08 ms` (**`1.76x`**), `in-2004` `6.68 -> 4.50 ms` (**`1.49x`**); `cage15 1M` `insert` `11.10 -> 8.15 ms` (**`1.36x`**); Dynamic TC post-insert accuracy restored (`dblp 100K` `17 -> 19`, `in-2004 100K` `1900 -> 1904`) |
| **DS-6** | Medium | `hornet_graph.cuh`, `memory_manager.cuh`, `block_array.cuh` | Full GPU-side CSR $\to$ Hornet initialization (`row_offsets`/`col_indices` upload + GPU bin prefix offsets + GPU edge scatter) | **Skipped intentionally** — CSR initialization is already covered by **DS-4** (OpenMP 2-pass degree histogram, `preallocate_bin_for_init`, concurrent staging) + **DS-1** (prefix-sized uninitialized staging + `cudaMallocAsync`); left out so `DS-1` + `DS-4` stay non-redundant and effort focuses on `DS-5` and `DS-7` | **Skipped (Covered by DS-1 + DS-4)** | `bench_init` already improved **`2.92x–19.29x`** (`142.6–503.7 ms` $\to$ **`7.39–155.75 ms`**) via `DS-1` + `DS-4`; remaining cost is one-time startup overhead rather than per-batch update latency |
| **DS-7** | Hard | `bit_tree.cuh`, `block_array.cuh`, `memory_manager.cuh`, `hornet_graph.cuh`, `gpu_allocator.cuh`, `batch_workspace.cuh`, `batch_insert.cuh`, `batch_delete.cuh` | Move `BitTree` bitmasks and block allocation/reclamation to GPU via warp-aggregated atomics (`__ffsll`, `atomicAnd`/`atomicOr`, overflow slab handling) | Moved flat 64-ary OR `BitTree`s + `free_count[]` + `first_nonfull_ba[32]` cursors + sorted `{base_ptr, ba_idx}` lookup tables to GPU VRAM (`sync_all_bins_to_device` at end of `init_from_csr`); replaced `BPlusTree`/`std::map` hot path and per-vertex D2H/H2D pointer ping-pong in `batch_insert` and `batch_delete` with GPU bin-grouped `ds7_gpu_allocate_blocks` (32-int `d_bin_deficit` pre-check + one-shot DS-1 fallback + single/CTA/32-CTA `BitTree` claim) and separate post-move GPU reclamation (`O(log #BAs)` binary search + `atomicOr` upward propagation + `__match_any_sync` warp-aggregated `atomicAdd`/`atomicMin`) | **Done** | Host serial share **`0.0%`** (`0.00 ms` across all 5 graphs); `1M` insert **`3.05x–10.67x` faster** (`1.75–6.90 ms`, up to **`571.9M upd/s`** on `dblp`); `10M` insert **`3.07x–7.33x` faster** (`343.8M–880.2M upd/s`); `1M` delete **`2.13x–7.36x` faster** (`10M` delete up to **`8.79x`** / `6.38B upd/s` on `dblp`); `ba_exp=16/19` `1M` insert **`4.81x–6.58x`** (`in-2004`, `kron`); `bench_tc` `100K` **`1.72x–5.78x`**; `bench_ktruss` `cage15` **`2.36x`** (`560.8M upd/s` peak) & `dblp` **`1.54x`** (`186.9M upd/s` peak); `nsys` `dblp 1M` `ds7_reclaim` `39.1 us` |
